# Firmware Motiva ESP32-CAM

Esta pasta receberá o firmware da ESP32-CAM do projeto Motiva ESP.

- Placa: AI Thinker ESP32-CAM.
- Sensor atual: OV3660.
- Compilação e envio: Arduino IDE.
- A ESP32-CAM acessará o backend local pelo endereço IPv4 do PC na rede, nunca por `localhost`.

Credenciais de Wi-Fi, como SSID e senha, não devem ser versionadas no repositório.
