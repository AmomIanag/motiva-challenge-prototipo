# Marca Motiva

Adicione neste diretório o arquivo oficial da marca com o nome:

```text
motiva-logo-anil.svg
```

O dashboard tenta carregar esse asset automaticamente com o componente `Image` do Next.js. Enquanto o arquivo não existir ou não puder ser carregado, a interface mantém o texto simples “Motiva” como placeholder.

Não substitua o arquivo por uma reprodução ou aproximação não oficial da marca.
